# B1 Builders Project

This repository contains the Geopolitical Market Forecaster prototype and supporting project notes.

## Project Structure

- `Documents/` - source notes and project concept documents.
- `IMPLEMENTATION_PLAN.md` - living implementation roadmap.
- `PROMPT_ACTION_LOG.md` - user prompts and minimal action summaries.
- `TOOLING.md` - local system tools and VS Code extensions used for the project.
- `project 1/` - scaffolded FastAPI prototype.

See `project 1/README.md` for local setup and run commands.

## Current Phase

Phases 0, 1, and 2 are complete. The next implementation phase is Phase 3: a dashboard for reviewing latest news, insights, forecasts, confidence, and governance state.
